# Headwind 개발 서버 → 운영 서버 이전 계획

## 확인된 현재 상태 (2026-10-09)

- 개발 Headwind는 5.41.1, Agent는 6.39를 사용한다.
- PostgreSQL의 `devices` 테이블에는 `WTK-051D` 한 대만 등록되어 있다. 관리자 화면에서 2대로 보인다면 현재 DB 조회 결과와 차이가 있으므로, 이전 전에 목록을 대조해야 한다.
- `Common - Minimal` 설정의 `newserverurl` 값은 비어 있다. 아직 운영 URL을 입력하거나 기기를 다른 서버로 이동하지 않았다.
- 운영 서버의 실제 접속 주소와 인증서가 확정되기 전에는 새 서버 주소를 설정하지 않는다.
- 개발 서버의 기준 주소는 기존 Ethernet `192.168.100.50`으로 유지한다. 2026-10-09 PC Wi-Fi 주소 변경으로 발생한 혼선을 피하기 위해 Headwind와 커스텀 Agent 설정을 이 기준 주소로 되돌려 정렬했다.

## 지원되는 이전 방식

Headwind Agent는 서버에서 내려주는 **New server URL** 설정을 통해 기존 Agent를 새 Headwind 서버로 이동할 수 있다. Agent 6.39 소스에는 서버 URL migration 처리가 포함되어 있다. Headwind 안내는 새 서버를 먼저 준비하고 설정/앱/기기 정보를 옮긴 다음, 기존 서버 설정에 새 URL을 지정하도록 설명한다: [Headwind 서버 이전 안내](https://qa.h-mdm.com/5806/how-to-migrate-to-the-new-server-change-server-url), [등록 기기 이전 절차](https://qa.h-mdm.com/17774/enrolled-devices-migration).

## 운영 이전 실행 순서

1. 운영 호스트와 실제 URL/IP를 확정한다. TCP 8443 HTTPS, TCP 31000 MQTT(현재 운영 정책이 polling을 유지한다면 MQTT는 별도 확인), 인증서 SAN 및 Android Agent가 신뢰할 CA를 검증한다.
2. 운영 Headwind를 개발 환경과 호환되는 버전으로 기동한다. 앱 파일, 구성, 설정을 복사하고 기기 레코드를 가져온다. 운영 DB/볼륨 백업을 먼저 만든다.
3. 기기 한 대만 canary로 선정한다. 현재 화면과 DB에서 대상 기기 번호 및 구성을 서로 대조한다.
4. 개발 서버의 대상 구성 `MDM settings`에서 **New server URL**에 운영 HTTPS 주소를 설정하고 저장한다. 공용 구성이라면 해당 구성을 사용하는 단말 모두에 적용되므로, 한 대씩 시험하려면 먼저 별도 canary 구성을 만들고 대상 단말만 배정한다.
5. 기기가 온라인 상태일 때 설정 갱신을 보내고, 운영 Headwind에 단말이 나타나는지, Agent 상태/앱 설치 상태가 정상인지 확인한다. 실패하면 두 번째 단말은 이동시키지 않는다.
6. canary 성공 후 나머지 단말을 같은 방식으로 순차 이전한다. 개발 서버는 전환 검증과 롤백 기간이 끝날 때까지 유지한다.

## 현재 막힌 부분과 신규 기기 시험

- 운영 IP/URL과 운영 인증서가 아직 확정되지 않아 지금 `newserverurl`을 적용할 수 없다. 임의 주소를 저장하면 Agent가 접속 불가능한 서버로 이동할 수 있다.
- 현재 DB에 등록된 기기는 한 대뿐이다. 화면에 두 대가 표시되면 두 번째 기기 번호를 확인한 뒤 이전 대상을 확정한다.
- 새 기기의 입고상태 시험은 별도 시나리오다. 공장 초기화 후 Device Owner 등록이 필요하며, 이 RK3566 장비에서 터치/카메라가 없고 ADB만 무선으로 켜 둔 경우 초기화 후 ADB 페어링이 사라질 수 있다. 초기화 전에 USB/물리 입력 또는 제조사 프로비저닝 경로를 확보해야 한다.
- 개발용 기존 커스텀 Agent APK 산출물은 이전 주소를 포함할 수 있으므로 사용하지 않는다. 소스 기본값은 `192.168.100.50`으로 정렬했으며 재빌드·기기 테스트가 필요하다. 운영 주소/CA로 다시 빌드하고 운영용 서명키로 서명하기 전에는 운영 단말에 배포하지 않는다. 세부 사항은 [CUSTOM_AGENT_BUILD.md](CUSTOM_AGENT_BUILD.md)를 참조한다.
