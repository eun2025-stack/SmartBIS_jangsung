# System Requirement Specification v1.1

## 1. 목적과 범위

SmartBIS는 차량 Android 클라이언트가 정류소 도착정보와 승인된 콘텐츠를 표출하도록 하는 서버·클라이언트 시스템이다. 브라우저 관리자 화면, 외부 Tomcat, /sht_webapp/는 범위에서 제외한다.

## 2. TAGO 요구사항

### SR-TAGO-01

서버는 TAGO 버스정류소정보 API로 정류소 ID, 명칭, 위도, 경도, 지역 정보를 수집한다.

### SR-TAGO-02

서버는 TAGO 버스노선정보 API로 노선과 경유 정류소 순서를 수집한다.

### SR-TAGO-03

서버는 차량번호, 도시코드, 노선 ID를 관리한다.

### SR-TAGO-04

TAGO 버스위치정보 API는 cityCode + routeId로 호출하고, 응답 vehicleno를 차량번호와 대조한다. Android는 TAGO API를 직접 호출하지 않는다.

### SR-TAGO-05

TAGO GPS 위치와 다음 정류소 좌표를 서버에서 비교하여 100m 이내 여부를 계산한다. Android GPS는 필수가 아니다.

```text
차량번호 일치
+ 노선·방향 일치
+ 다음 정류소 결정
+ 차량 좌표와 정류소 좌표 거리 <= 100m
= 도착정보 표출 상태
```

## 4. 콘텐츠 신청과 승인

```text
DRAFT → SUBMITTED → APPROVED → ACTIVE → EXPIRED
                    └→ REJECTED
```

승인되지 않은 콘텐츠는 Android 표출 API에 포함하지 않는다. 표출 시작·종료, 지역 제한, 우선순위, 반복 간격, 최소 표출시간, 강제 표출 여부, 승인자와 승인시각을 관리한다.

## 5. 재난문자

행정안전부 긴급재난문자는 API 신청 전까지 외부 API를 호출하지 않는다. 다음 내부 계약과 DB 샘플로 전체 처리를 검증한다.

```text
disaster_id
message_text
disaster_type
issued_at
expires_at
target_regions
severity
status
source
```

외부 승인 후 수집기만 교체하며 표출 엔진과 Android API 계약은 유지한다.

## 6. 표출 우선순위

지역 내 기본 순위:

```text
관리자 강제 표출 > 정류소 도착정보 > 재난정보 > 지역 제한 콘텐츠 > 행사·공지
```

지역 외 기본 순위:

```text
관리자 강제 표출 > 정류소 도착정보 > 재난정보 > 행사·공지
```

서버가 명시한 우선순위가 있으면 기본 순위보다 우선한다.

## 7. Android 요구사항

Android는 GET /api/v1/display/next?vehicleNumber={차량번호}로 서버가 계산한 표출 항목을 조회한다. Android는 차량 위치 계산이나 TAGO 키 관리를 하지 않는다.

미디어는 Room과 임시 파일을 사용하고, 다운로드 완료 후 원자적으로 확정한다. VIDEO는 ExoPlayer, IMAGE와 CARD는 전체 화면 템플릿으로 표시한다.

화면은 1920x1080 전체 영역을 사용하고 프레임 분할을 기본으로 하지 않는다. 노약자 가시성을 위해 큰 글자, 높은 명암 대비, 짧은 문장, 자동 줄바꿈을 적용한다.

## 8. 표출정보 API

```text
GET /api/v1/display/next?vehicleNumber={차량번호}
```

응답은 displayType, priority, within100m, currentStop, nextStop, distanceMeters, contentId, template, text, expiresAt을 포함한다.

## 9. 운영 현황

서버는 현재 차량·노선·정류소, TAGO 마지막 수집시각, 수집 실패, 활성 재난문자, 승인·대기·반려 콘텐츠, 현재 표출, Android 마지막 동기화, 미디어 다운로드 실패를 조회할 수 있어야 한다.

## 10. 검증

1. 차량번호로 등록 차량 조회
2. cityCode·routeId 기반 TAGO 호출
3. vehicleno 대조
4. 다음 정류소와 100m 판정
5. 지역 콘텐츠 필터
6. DB 샘플 재난문자 활성화
7. 우선순위 검증
8. 승인 전 콘텐츠 제외
9. 1920x1080 템플릿 표시
10. TAGO 장애와 Android 캐시 검증
