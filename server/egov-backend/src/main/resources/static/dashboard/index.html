‘중지’는 다음 표출 선택부터 제외하고, ‘게시 제외’는 홍보 목록과 표출 대상에서 제외합니다. 둘 다 DB 콘텐츠와 미디어 파일·수신 이력은 보존합니다. 변경자는 로그인한 관리자 계정으로 자동 기록됩니다.

표출 정책
유형별 표출 시간·반복 간격·우선순위·사용 여부를 변경합니다. 행마다 저장하면 정책 DB에 반영됩니다.

        
협의 반영 예정: 새 카드뉴스는 전체 재생 종료 시 전환합니다. 현재 DB의 CARD는 기존 텍스트형 코드이므로 아직 새 카드뉴스로 변경하지 않았습니다. 재난 반복 간격도 기존 값을 유지합니다.

        
변경자는 로그인한 관리자 계정으로 자동 기록됩니다. 시간 공란은 제한 없음으로 저장됩니다. 동영상 시간 공란은 재생 종료 전환을 위한 설정입니다.
